A LITTLE GUIDE

One link, fewer blank fields.

Paste the Novel Updates page for the novel. The link joins the Conservatory's private editorial review queue.

  1. Copy the exact series URL, even if your novel already has it linked. Select the missing or outdated fields you want the editor to check.
  2. The editor attempts to retrieve the original Novel Updates synopsis, genres, tags, author and available cover reference.
  3. If automated retrieval is blocked, the editor can use the existing authorized browser-assisted capture workflow.
  4. After checking the existing novel, an editor can approve real source metadata. Cover artwork requires separate permission and attribution review.

Nothing is made up, and submissions aren't automatically published. You do not need an account to suggest a link.
