How access works

Invited readers can browse novel metadata and translator links. They cannot edit novels or automatically read private EPUBs.

One-time Cloudflare setup required

Keep Cloudflare Access authentication enabled. Configure an Allow policy for verified email logins (not a Bypass policy), then the Conservatory's own member list blocks anyone who has not been approved.

Until this is configured, friends outside the current Cloudflare Access allowlist will be blocked at login, even with a valid invitation.

Cloudflare will authenticate the email address. The website independently checks every file and API request against the approved-reader list. Make sure your D1 binding is named DB.

For EPUB reading, use the separate “Approved readers” setting, and enable it only when you have sharing rights.

Invitation history

Pending links can be canceled. Accepted links have no usable code remaining. The code itself is never stored here.
