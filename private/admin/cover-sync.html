Sync existing covers

One-time transfer of old private cover images to the shared public cover collection.

What this sync does

Copies existing private cover images from novel-conservatory-covers to novel-conservatory-community-art, then publishes only the image URL for the matching novel.

No EPUBs, chapters, private shelves or member data are transferred. Books with an already published public cover are skipped. This does not extract previously uploaded EPUBs that have no separate stored cover yet.

Older EPUBs without extracted covers?

If a book has only an EPUB in private R2 and no separately saved cover image, a safe R2-to-R2 cover copy cannot extract artwork from the EPUB. For those, use the existing Change covers tool or import the EPUB again using the bulk editions uploader, which now extracts covers automatically. The original EPUB remains private.
