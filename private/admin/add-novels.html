Optional cover

Import many novel entries

Upload a CSV or JSON file with columns such as title, originalTitle, author, translator, language, synopsis, genres, tags, nuUrl, translatorUrl, originalUrl, sourceUrl. Missing columns are optional, but titles are required. Imports are done in batches of 100.

Duplicate titles are skipped and listed in the results. Bulk imports never automatically upload or share EPUBs.

Upload EPUB editions

Select a newly created novel, then choose one or more EPUBs. Each file becomes a separate translation edition, uploaded in resumable 8 MiB pieces. Files stay in the private R2 storage.

Extract EPUB metadata

Read the embedded description, creator, title and subjects from a selected EPUB. Review before applying to a catalogue entry. This does not send the novel text to any AI service or publish it.

Missing descriptions and tags cannot be inferred reliably from the package alone. Use Novel Updates or editorial review to fill these gaps.

Manage added novels

Edit any additional novel, change whether its metadata is public, or replace a cover. This never changes the original 962 records or exposes EPUB files.

View change history & Undo ↗

Editor changes take effect immediately. They do not enter an approval queue. Undo restores the previous metadata and publication status unless another edit has changed the book.
