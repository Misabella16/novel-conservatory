Google Sheets & backups

Review every import. Preserve the master catalogue.

1. Export your current catalogue

Download separate CSV files for the novel catalogue and all translation editions. Import the CSV into Google Sheets. Both exports include your saved corrections.

Download private JSON backup

The JSON backup is owner-only, contains membership emails and report metadata, and excludes EPUB files, invitation tokens and your friends' private shelves. Store it securely.

2. Import your edited Translations tab

In Google Sheets, use File → Download → Comma-separated values (.csv), then choose that exported file here. The preview groups edits by novel ID. Importing updates translation editions only, never covers, synopsis or reader permissions.

What about automatic Google Sheets sync?
This update provides manual round-trip CSV synchronization. It does not connect to Google OAuth or modify your original Sheet behind the scenes. A secure automatic sync would require a separate account connection and explicit conflict-resolution rules.
Translation columns: novelId, editionIndex, title, translator, label, language, status, readUrl, siteUrl, chaptersTranslated, totalChapters, lastUpdated, notes.
