Reader-submitted Novel Updates links

Readers submit a Novel Updates series URL. Choose Retrieve & preview NU metadata to collect the actual title, author, synopsis, genres and tags. For an existing novel, select the fields to import and explicitly approve the update. Missing-only is the default, and the original book record is never duplicated.

Source-only metadata. Retrieval may be blocked by Novel Updates (403/429). If that happens, capture the original series page with the existing browser bookmarklet, then paste the captured JSON into the request panel. Nothing is guessed or published automatically. Existing translator links, titles, covers and translation statuses are protected.
