Bulk fill from Novel Updates

Fill in missing tags, genres, synopses and covers for many novels at once.

Step 1 · Collect from Novel Updates in your own browser

Novel Updates blocks automatic requests from servers, so this happens in a Novel Updates tab you open yourself. The script reads one series page every few seconds. If Novel Updates asks you to verify you are human, the script stops; you complete the check yourself and paste the script again to continue where it left off.

Loading…

  1. In Chrome, Safari or Firefox on a computer, open https://www.novelupdates.com/ in a new tab. Complete the “verify you are human” check if it appears.
  2. Open the developer console in that tab: Chrome ⌘ ⌥ J, Firefox ⌘ ⌥ K, Safari ⌘ ⌥ C (turn on Settings › Advanced › Show features for web developers first). If the browser asks you to type “allow pasting”, do that.
  3. Paste the script and press Return. A small green panel shows progress. Leave the tab open; you can use other tabs meanwhile.
  4. When it finishes, it downloads a nu-bulk-date.json file. Use Download file in the panel at any time to take what has been collected so far.

Only paste scripts you built on this page into a console. This one only reads Novel Updates series pages in that tab and saves its progress in that browser; it sends nothing anywhere.

Step 2 · Fill your catalogue from the file

Each novel goes through the same importer as the Novel Updates option on a novel’s page: only empty fields are filled, tags and genres are added without removing yours, everything stays private, and every novel gets its own Undo.
